安装教程

1️⃣ 下载光影包 MediaFire下载页 ↗
2️⃣ 对于安装包版本
下载光影压缩包 (如[2.4][Android] Dawnlight v2.5.zip)
找到压缩包内的APK文件 (如Survivalcraft 2.4 With Dawnlight v2.5.apk)


安装Apk
(共存版: 与官方Api版本共存，且存档独立存储于文件夹 [通常为/storage/emulated/0/Survivalcraft2.4_Dawnlight/])
2️⃣ 对于Windows版本
安装.Net10.0 (9.0)运行时


下载光影压缩包 (如[2.4][Win64] Dawnlight v2.5.zip)




解压并启动： 

Folder/
└─ Survivalcraft.exe
2️⃣ 对于Mod版本 解压并放入目录： 

Survivalcraft/
└─ Mods/
   └─ Dawnlight.scmod
2️⃣ 对于Linux版本
安装.Net10.0 (9.0) 
# Ubuntu | Debian

# 更新包列表
sudo apt update

# 安装.NET 10.0运行时
sudo apt install -y dotnet-runtime-10.0

# 检查安装是否成功
dotnet --list-runtimes

# 或查看版本
dotnet --info
    
# Arch | Manjaro
      
# 更新包数据库
sudo pacman -Syu

# 安装.NET 10.0运行时
sudo pacman -S dotnet-runtime-10.0

# 检查版本
dotnet --version



解压并启动： 

user@localmachine:~# ./Survivalcraft
3️⃣ 启动游戏(确保版本匹配)
推荐配置 & 常见问题

推荐配置：


CPU:
AMD Ryzen 5 6600H
Intel i5-12500H

内存:
12GB DDR4 3200

显卡:
NVIDIA 1060
AMD RX580
Intel Arc A580

光影配置:
ViewDistance = 368
Shadow = ON
VolumetricLight = ON
WaterEffect = ON

菜单快捷键: U (暂不支持更改热键)

若视觉上屏幕过亮或对比度过高，可以在设置中切换Tonemapping(色调映射)

[Linux] 若生成世界时崩溃，请先将视距调整至最低，等待进入游戏后再恢复视距


关于API版本、模组安装: Dawnlight 2.5的API版本为1.8.2.3，但接口和依赖版本并非与中文官方版完全一致，且光影对渲染管线等进行了修改，可能导致模组兼容性问题。

若您不幸遇到了此类问题，请发送邮件到annularwind@outlook.com或到QQ开发群739289392进行反馈。

目前已知兼容的模组: 美好时代, 十亿伏特, 铃兰辅助等, 欢迎继续补充.


若出现性能问题，请参考 性能优化指南 ↗
