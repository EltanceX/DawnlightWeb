光影包介绍

一款为提升 Survivalcraft 视觉体验而生的光影包，优化方块世界的细节与氛围感，兼顾视觉震撼与运行流畅度，适配各类建筑展示、生存冒险与风景观光场景，让每一次探索都充满沉浸式惊喜。

核心特性

☀️ 实时阴影与软阴影
告别生硬色块，光影过渡自然柔和，还原真实光影投射逻辑，让每一处角落都充满层次感。
🌿 植被交互效果
风吹草动皆有反馈，植被摇曳细腻逼真，让场景更具生机与活力。
☁️ 体积云与大气散射
云层层次分明，随昼夜与天气动态变化，搭配四季专属大气散射效果。
🌙 夜间渲染增强
搭配体积光与泛光效果，火把、灯笼等光源照亮路径的同时呈现自然光影衰减。
💎 PBR材质渲染
真实物理材质渲染，还原不同方块的物理质感，金属的光泽、石头的粗糙都清晰可见。
💧 屏幕空间反射
地面积水、雨涟漪效果逼真，水面倒映周围景致，雨天更具沉浸感。

四季适配：每一季都有独特的视觉质感。

安装教程

1️⃣ 下载光影包

前往下载页面获取最新版本：

MediaFire下载页 ↗
2️⃣ Android 安装包版本

下载光影压缩包（如 [2.4][Android] Dawnlight v2.5.zip）

找到压缩包内的APK文件（如 Survivalcraft 2.4 With Dawnlight v2.5.apk）

安装APK文件

💡 共存版：与官方API版本共存，存档独立存储于 /storage/emulated/0/Survivalcraft2.4_Dawnlight/

2️⃣ Windows 版本

首先安装 .NET 10.0（或 9.0）运行时：

下载光影压缩包（如 [2.4][Win64] Dawnlight v2.5.zip）

解压并启动：

目录结构 
Folder/
└─ Survivalcraft.exe
2️⃣ Mod 版本

解压并放入目录：

目录结构 
Survivalcraft/
└─ Mods/
   └─ Dawnlight.scmod
2️⃣ Linux 版本

首先安装 .NET 10.0（或 9.0）运行时：

Ubuntu | Debian 
# 更新包列表
sudo apt update

# 安装.NET 10.0运行时
sudo apt install -y dotnet-runtime-10.0

# 检查安装是否成功
dotnet --list-runtimes

# 或查看版本
dotnet --info
Arch | Manjaro 
# 更新包数据库
sudo pacman -Syu

# 安装.NET 10.0运行时
sudo pacman -S dotnet-runtime-10.0

# 检查版本
dotnet --version

解压并启动：

命令行 
user@localmachine:~# ./Survivalcraft
3️⃣ 启动游戏

确保版本匹配后启动游戏即可体验光影效果。

游戏内按下U键可调用光影菜单

推荐配置 & 常见问题

推荐配置

硬件要求 
CPU:
  AMD Ryzen 5 6600H
  Intel i5-12500H

内存:
  12GB DDR4 3200

显卡:
  NVIDIA 1060
  AMD RX580
  Intel Arc A580

光影配置:
  ViewDistance = 368
  Shadow = ON
  VolumetricLight = ON
  WaterEffect = ON

⌨️ 菜单快捷键：U（暂不支持更改热键）

📱 手机端推荐性能优化：更好的树叶[关闭] 软阴影[关闭] 波浪更新[禁用]

🎨 若视觉上屏幕过亮或对比度过高，可以在设置中切换 Tonemapping（色调映射）

⚠️ [Android] 联发科设备可能由于不支持SSBO特性导致兼容性问题，若遇到请尝试更换其他平台的处理器

⚠️ [Linux] 若生成世界时崩溃，请先将视距调整至最低，等待进入游戏后再恢复视距


关于API版本、模组安装：Dawnlight 2.5的API版本为1.8.2.3，但接口和依赖版本并非与中文官方版完全一致，且光影对渲染管线等进行了修改，可能导致模组兼容性问题。

若您不幸遇到了此类问题，请发送邮件到 annularwind@outlook.com 或到 Discord / QQ开发群 进行反馈。

目前已知兼容的模组：美好时代、十亿伏特、铃兰辅助等，欢迎继续补充。


若出现性能问题，请参考 性能优化指南 ↗
